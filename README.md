
# Lokman Sharif — Portfolio & Blog

This is a simple, fast, responsive portfolio with a built‑in blog powered by Jekyll (works on GitHub Pages).

Edit these files to personalize:
- `index.html` — hero text, skills, projects, contact links.
- `style.css` — colors and spacing (supports dark/light mode automatically).
- `_config.yml` — site title/description.

Blogging:
- Create new posts in `_posts/` named like `YYYY-MM-DD-title.md` with front matter:

	---
	layout: post
	title: "My New Post"
	description: "Optional short summary"
	---

	Your Markdown content here.

- Your latest posts show on the homepage. All posts are listed at `/blog/`.

Local preview (optional): if you have Ruby and Bundler, you can run Jekyll locally.
1) Install dependencies
2) Serve the site

GitHub Pages will build automatically on push.
